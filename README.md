# Rui

A general-purpose Linux image for sekai-station development.

## Language Environments

- Go 1.27
- Node.js 26
- Python (uv)

## Usage

Create `.devcontainer/devcontainer.json` in your project:

```json
{
  "name": "Rui",
  "image": "ghcr.io/sekai-station/rui:latest",
  "remoteUser": "vscode"
}
```
